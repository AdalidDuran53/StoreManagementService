# StoreManagementService (SMS)
Modular service for store management, designed with clean architecture, reusable patterns, and scalability focus.

---

🚀 Key Features
- RESTful API in .NET Core 3.1 with secure authentication
- Structured logging and controlled error handling
- Reusable helpers for product, customer, and sales management

---

🧱 Project Structure
├── DTOs/                       # # Custom and keyless models
├── ExceptionsManagement/       # Controlled exceptions and helpers
├── StoreManagementService/     # Implementation and business rules
├── database/                   # Database scripts
├── StoreManagementService.sln  # Solution file
└── .gitignore                  # Git ignore rules
